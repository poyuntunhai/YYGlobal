# Program Research

把检索目标拆成学校、QS 排名、国家、专业和其他硬性要求。项目发现必须逐步执行“定位目录 → 程序读取目录并提取链接 → 模型从 URL 白名单选择项目或下一层目录 → 独立模型核验具体项目页”。目录定位模型禁止直接生成项目 URL，项目选择模型禁止输出输入目录中不存在的 URL。指定学校时以学校为最高优先级并忽略冲突的国家限制；未指定学校时先从国家与 QS 范围选择一批学校，再逐校执行相同目录流程并交错取样。

每批 5 个是目标数量。通过核验的项目不足 5 个时，应继续遍历尚未检查的目录链接、学院目录或下一批符合条件的学校。只有目录及其分页已经完成遍历且连续两轮没有新增候选时，才能声称“没有更多符合条件的项目”。每个候选必须记录目录来源；被拒绝的项目必须保留结构化拒绝原因。项目身份必须由不同于检索模型的独立模型复核，之后再完成官网要求与原文证据核验，未通过独立审计的项目不得发布。
